## 2. GitHub Quickstart & Push Commands

To initialize git in this folder and push your repository to GitHub:

```bash
cd "c:\Users\sunit\Desktop\cp-calender"

# 1. Initialize Git
git init

# 2. Add all files
git add .

# 3. Create initial commit
git commit -m "feat: initial release of CodeRadar v1.0.0 (Contest Radar & Multi-Platform HUD)"

# 4. Set default branch to main
git branch -M main

# 5. Connect to your GitHub repo (replace <username> and <repo-name>)
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/coderadar.git

# 6. Push to GitHub
git push -u origin main
```
